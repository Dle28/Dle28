# Setup

1. Create a public repository named exactly `Dle28`.
2. Copy `README.md` to the repository root.
3. Create an `assets` folder and place `dark-cave-banner.svg` inside it.
4. Commit and push the files.
5. Open `https://github.com/Dle28` to verify the profile README.

Repository structure:

```text
Dle28/
├── README.md
└── assets/
    └── dark-cave-banner.svg
```

Notes:

- The design intentionally excludes project cards and GPA.
- Edit the skill levels in `04 / CURRENT DEPTH` when needed.
- GitHub may cache SVG changes; rename the SVG or wait for the cache to refresh after major edits.
